# PV-ADR-TASK-3
Causality Assessment in Pharmacovigilance
This task focuses on Causality Assessment in Pharmacovigilance, including the assessment of drug-event relatedness using the Naranjo Algorithm and WHO-UMC Causality Assessment System. It also covers implied causality and causality assessment for vaccines (AEFI).

Topics Covered:
Causality Assessment
Factors affecting causality
Naranjo Algorithm
WHO-UMC Causality Assessment
Implied Causality
Vaccine Causality Assessment (AEFI)
